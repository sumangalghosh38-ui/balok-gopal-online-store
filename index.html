📥 Bulk Import Categories & Sub-Categories (JSON) — বাল্ক ক্যাটাগরি ইম্পোর্ট

Paste JSON below and click Import. Categories/sub-categories that don't already exist (matched by English name, case-insensitive) will be created. Ones that already exist are left untouched — so it's safe to re-paste the same JSON. Photos aren't set this way; add them later from the forms above if needed.

Two formats are accepted — a flat list (one row per sub-category): 

[
  { "category": "Grocery", "categoryBn": "মুদি", "subCategory": "Flour", "subCategoryBn": "আটা" },
  { "category": "Grocery", "subCategory": "Rice", "subCategoryBn": "চাল" }
]

…or grouped (one row per category, with a list of sub-categories — use an empty/omitted subCategories list to add a category with no sub-categories yet): 

[
  {
    "category": "Grocery",
    "categoryBn": "মুদি",
    "subCategories": [
      { "en": "Flour", "bn": "আটা" },
      { "en": "Rice", "bn": "চাল" }
    ]
  },
  { "category": "Snacks", "categoryBn": "নাস্তা" }
]

📥 Bulk Import Products (JSON) — বাল্ক প্রোডাক্ট ইম্পোর্ট

Paste a JSON array of products below and click Import. Any Category or Sub-Category named in the JSON that doesn't already exist will be created automatically. A product that already exists (same sub-category + name + size) will be updated instead of duplicated — so it's safe to re-paste the same file.

Expected format — a plain array, or {"products":[...]}: 

[
  {
    "category": "Grocery",
    "subCategory": "Flour",
    "nameEn": "Wheat Flour",
    "nameBn": "আটা",
    "containerSize": "1 kg",
    "price": 50,
    "unit": "perPacket",
    "discountType": "flat",
    "discount": 10
  }
]

unit: perKg / each / perPacket (Per Packet, Per Bottle, Per Jar all map to perPacket)  ·  discountType: flat or percent
